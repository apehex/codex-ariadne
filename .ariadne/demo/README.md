# Ariadne synthetic trace demo

This demo generates a deterministic, entirely synthetic rollout-trace bundle and opens it through the normal `codex trace --bundle` interface.
It does not use authentication, make network requests, read Codex session history, enable tracing, or introduce a demo-only trace schema.

## Prerequisites

- Python 3.10 or newer;
- an interactive terminal;
- an Ariadne build installed as `codex-ariadne`, following the [release-candidate build instructions](../releases/2026-07-28-trace-browser-rc.md).

## Run

From the repository root:

```console
python .ariadne/demo/demo.py run
```

The launcher creates the bundle in a temporary directory, runs `codex-ariadne trace --bundle <directory>`, and removes only that temporary directory after the browser exits.
Pass another executable with `--binary`, for example:

```console
python .ariadne/demo/demo.py run --binary ./codex-rs/target/release/codex
```

To retain a bundle for inspection, generate it at a new or empty path and launch the browser directly:

```console
python .ariadne/demo/demo.py generate ./ariadne-synthetic-bundle
python .ariadne/demo/demo.py verify ./ariadne-synthetic-bundle
codex-ariadne trace --bundle ./ariadne-synthetic-bundle
```

The generator refuses to overwrite a non-empty directory.

## What the bundle demonstrates

The fixed scenario contains a root thread, three model calls, one delegated child thread, spawn and result-delivery interactions, raw request and response payloads, completed turns, and a completed rollout.
All identifiers, timestamps, paths, prompts, responses, and tool data are synthetic constants defined in [`demo.py`](demo.py).
The generated files use the existing version-1 rollout-trace manifest, event spine, and bundle-local payload layout.

In the browser, use the on-screen key guide to expand nodes, move between panes, search for `deterministic`, and open a collapsed raw payload.

## Determinism and privacy

`verify` compares every generated byte and relative path with the generator's current expected output.
CI also replays the generated bundle with the repository's Rust reducer, which detects drift between the Python demonstration and the authoritative bundle implementation.

Do not replace this scenario with a captured or redacted trace.
Real traces can contain prompts, responses, commands, tool inputs and outputs, terminal output, and private paths; they remain sensitive local data even when they appear harmless.
