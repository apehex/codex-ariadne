# Ariadne

Ariadne is a public fork of [OpenAI Codex](https://github.com/openai/codex) focused on local inspection of agent execution traces.

Ariadne is not an OpenAI product and is not endorsed by OpenAI. The fork preserves Codex's Apache-2.0 license and notices.

Project identity, governance, architecture, planning, privacy, and development routes are indexed in [`.ariadne/README.md`](.ariadne/README.md).

To evaluate the historical browser without replacing an upstream Codex installation, build the fork as `codex-ariadne` and run its deterministic synthetic demo using the [release-candidate instructions](.ariadne/releases/2026-07-28-trace-browser-rc.md).
